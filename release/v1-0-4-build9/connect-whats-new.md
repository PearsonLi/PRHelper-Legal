# What's New (v1.0.4 build 9)

## EN
Release: v1.0.4 (build 9)
Compared with v1.0.4 (build 8):
- Fixed a commercial data-recovery issue so family member data is preserved more reliably after reinstall/cloud restore.
- Tightened free-tier capacity guard to prevent trip-limit bypass paths while keeping existing records safe.
- Improved Overview layout: “Family Overview” is now inline with the profile switcher for quicker access.
- Updated release-scoped legal pages and aligned privacy wording with current app behavior.

## ZH
发布版本：v1.0.4（build 9）
相较于 v1.0.4（build 8）：
- 修复商用数据恢复问题：重装/云端恢复后，家庭成员数据可更可靠地保留与恢复。
- 收紧免费容量边界，补齐旅行记录超限规避路径，同时保证已有数据安全。
- 优化总览页布局：“全家总览”与成员切换入口并排显示，访问更直接。
- 更新本版本法务页面，并使隐私条款文案与当前实现保持一致。
