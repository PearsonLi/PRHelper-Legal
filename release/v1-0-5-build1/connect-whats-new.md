# What's New (v1.0.5 build 1)

## EN
Release: v1.0.5 (build 1)
Compared with v1.0.4 (build 8):
- Fixed migration/recovery behavior so family-member data is preserved more reliably after reinstall/cloud restore.
- Closed capacity bypass paths for free-trip limits to keep free/pro/family boundaries consistent.
- Improved Overview layout by placing “Family Overview” inline with member switching.
- Updated release-scoped legal pages and aligned Privacy wording with current implementation (no location-tracking feature).

## ZH
发布版本：v1.0.5（build 1）
相较于 v1.0.4（build 8）：
- 修复迁移/恢复路径，重装或云端恢复后家庭成员数据保留更可靠。
- 补齐免费旅行条数边界的规避路径，免费/专业版/家庭版能力边界更一致。
- 优化总览页布局，“全家总览”与成员切换入口并排展示。
- 更新本版本法务页面，隐私文案已与当前实现一致（不包含定位跟踪功能）。
