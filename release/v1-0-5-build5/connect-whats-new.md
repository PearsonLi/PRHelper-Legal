# What's New (v1.0.5 build 5)

## EN
Release: v1.0.5 (build 5)  
Compared with v1.0.5 (build 4):
- Fixed cloud restore reliability for family data: on reinstall/restore, trip history is now restored correctly even when local timestamp metadata survives uninstall.
- Fixed import/merge edge handling to prevent empty-snapshot overwrite and improve zero-absence trip consistency.
- Kept migration/data model unchanged; this is a compatibility and reliability patch release.

## ZH
发布版本：v1.0.5（build 5）  
相较于 v1.0.5（build 4）：
- 修复家庭数据云恢复可靠性：在重装/恢复场景下，即使本地时间戳残留，也能正确恢复旅行记录。
- 修复导入/合并边界处理：避免空快照覆盖，并提升“零缺席行程”导入一致性。
- 本次为兼容性与稳定性补丁版本，不改迁移版本和数据结构。
