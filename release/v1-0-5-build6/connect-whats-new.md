# What's New (v1.0.5 build 6)

## EN
Release: v1.0.5 (build 6)  
Compared with v1.0.5 (build 5):
- Rebuilt travel data handling to be Trip-first, improving consistency between edit/save/import/restore paths.
- Improved reliability for cloud restore and migration across historical commercial baselines, including family-member trip recovery scenarios.
- Improved app responsiveness for trip save, startup, and member switching.
- Fixed multiple edge-case issues around timeline display, date editing boundaries, and runtime stability.

## ZH
发布版本：v1.0.5（build 6）  
相较于 v1.0.5（build 5）：
- 旅行数据链路升级为 Trip-first，提升编辑、保存、导入、恢复的一致性。
- 加强云恢复与历史商用版本迁移可靠性，包含家庭成员旅行记录恢复场景。
- 优化旅行保存、应用启动与成员切换时的响应速度。
- 修复多项边界问题，包括时间线显示、日期编辑边界与运行稳定性。
