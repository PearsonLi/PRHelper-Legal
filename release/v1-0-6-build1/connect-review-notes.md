# Review Notes (v1.0.6 build 1)

## EN
Release: v1.0.6 (build 1)
- No account/login is required; core tracking and calculations run locally on device.
- Main paywall entry paths:
  1. Settings -> Unlock Pro
  2. Free-limit interception when creating/updating records beyond capacity
  3. Family-locked member switch/add/edit paths
- Purchase/restore/redeem paths:
  - Subscribe / Buy buttons in paywall cards
  - Restore Purchases (paywall footer)
  - Redeem Code (paywall footer)
- Entitlement model in this build:
  - Authorization is entitlement-first.
  - Active monthly subscription unlocks both Pro + Family capabilities.
  - Pro Lifetime unlocks Pro capability.
  - Family Lifetime unlocks Family capability and includes Pro capability.
  - When monthly expires, Pro + Family are relocked unless covered by lifetime entitlement.
- Free-tier capacity model:
  - Up to 5 total records per member (Trip + Temporary Residence combined).
- Temporary Residence path:
  - Travel -> History -> Temporary Residence (collapsible section).
- FAQ/rule explanation path:
  - Settings -> FAQ / 常见问题.
- Version-scoped legal URLs for this build:
  - Terms EN: https://pearsonli.github.io/PRHelper-Legal/terms/en/v1-0-6-build1/
  - Privacy EN: https://pearsonli.github.io/PRHelper-Legal/privacy/en/v1-0-6-build1/

## ZH
发布版本：v1.0.6（build 1）
- 应用无需账号登录，核心记录与计算默认在本地完成。
- 主要付费墙入口：
  1. 设置 -> 解锁专业版
  2. 免费容量超限时的新增/编辑拦截入口
  3. 家庭版未解锁时的成员切换/新增/编辑入口
- 购买/恢复/兑换路径：
  - 付费墙内订阅或买断按钮
  - 付费墙底部“恢复购买”
  - 付费墙底部“使用优惠码兑换”
- 本版本授权模型：
  - 授权判定以 entitlement 为准。
  - 月订阅有效期内：解锁 Pro + Family 能力。
  - Pro 买断：解锁 Pro 能力。
  - Family 买断：解锁 Family 多成员能力，并包含 Pro 能力。
  - 月订阅到期后：若无买断覆盖，Pro + Family 会重新锁定。
- 免费容量口径：
  - 免费版按成员计，最多 5 条总记录（旅行 + 临时居留合计）。
- 临时居留入口：
  - 旅行 -> 历史记录 -> 临时居留（可折叠区域）。
- 规则说明入口：
  - 设置 -> 常见问题。
- 本版本法务链接：
  - 服务条款（中文）：https://pearsonli.github.io/PRHelper-Legal/terms/zh/v1-0-6-build1/
  - 隐私政策（中文）：https://pearsonli.github.io/PRHelper-Legal/privacy/zh/v1-0-6-build1/
