# What's New (v1.0.6 build 1)

## EN
Release: v1.0.6 (build 1)  
Compared with v1.0.5 (build 6):
- Added a new default Calendar Mode for both PR and Citizenship pages, with month-by-month daily residency values for today through the next 3 years.
- Kept Trend Mode available and aligned day-count outputs across Travel indicators, Calendar Mode, and Trend evaluation for the same date.
- Moved Temporary Residence management to Travel -> History as a collapsible section to simplify citizenship-related data entry.
- Improved travel import/export reliability, including stricter JSON validation and better compatibility with legacy exported files.
- Improved overall stability and responsiveness in trip edit/save flows and release-path migration/restore handling.

## ZH
发布版本：v1.0.6（build 1）  
相较于 v1.0.5（build 6）：
- 永居与入籍页面新增默认“日历模式”，按月展示从今天起未来 3 年的每日居住天数。
- 保留“趋势模式”，并统一旅行信号、日历模式、趋势评估在同一评估日的天数结果。
- 将“临时居留”管理迁移至“旅行 -> 历史记录”的可折叠区域，录入路径更直观。
- 提升旅行导入导出可靠性，增强 JSON 校验并兼容老版本导出格式。
- 优化旅行编辑/保存以及迁移恢复链路的稳定性与响应速度。
