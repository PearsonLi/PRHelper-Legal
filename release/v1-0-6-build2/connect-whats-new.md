# What's New (v1.0.6 build 2)

## EN
Release: v1.0.6 (build 2)  
Compared with v1.0.6 (build 1):
- Improved tab-switch responsiveness (Overview / Travel / PR / Citizenship / Settings) by batching UI state updates and deferring heavy refresh work.
- Fixed free-limit counting so temporary-residence records are counted correctly without double counting.
- Improved overall stability in travel record save/edit flows under the latest trip-table architecture.

## ZH
发布版本：v1.0.6（build 2）  
相较于 v1.0.6（build 1）：
- 优化底部菜单切换响应速度（总览/旅行/永居/入籍/设置），通过批量状态更新与延后重计算降低卡顿。
- 修复免费上限计数问题，临时居留记录不再被重复计入。
- 提升旅行记录新增/编辑保存链路在 trip 主表架构下的稳定性。
