# Review Notes (v1.0.7 build 1)

## EN
Release: v1.0.7 (build 1)
- No account/login is required; core tracking and calculations run locally on device.
- Main paywall entry paths remain:
  1. Settings -> Unlock Pro
  2. Free-limit interception when creating/updating records beyond capacity
  3. Family-locked member switch/add/edit paths
- This build focuses on data consistency and UX stability:
  - member-switch transition lock until switch completion,
  - full-trip-table sync/migration for companion records,
  - simplified startup guidance behavior.
- Reviewer sanity path for this build:
  1. Open Settings -> Family/Member settings, switch between members.
  2. Confirm tab taps are blocked during switching and re-enabled after completion.
  3. Add/update a trip for companion and run sync/import migration path.
  4. Confirm companion trip history remains complete after data refresh.
