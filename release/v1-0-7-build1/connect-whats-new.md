# What's New (v1.0.7 build 1)

## EN
Release: v1.0.7 (build 1)  
Compared with v1.0.6 (build 2):
- Improved member-switch transition: tabs stay temporarily locked until switching completes, preventing accidental actions on stale state.
- Fixed companion-trip consistency in sync/migration by carrying the full trip table for all members, so companion records are no longer dropped.
- Simplified startup loading flow and removed redundant first-launch round-trip recheck guidance to reduce confusion.

## ZH
发布版本：v1.0.7（build 1）  
相较于 v1.0.6（build 2）：
- 优化成员切换过渡：切换完成前底部页签保持不可点击，避免在旧状态下误操作。
- 修复同行人数据在同步/迁移中的完整性问题：改为按完整 trip 主表同步，避免同行人旅行记录丢失。
- 精简启动流程并移除首次安装时冗余的“当日往返复查”提示，降低新用户困惑。
