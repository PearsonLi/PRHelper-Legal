# What's New (v1.0.7 build 3)

## EN
Release: v1.0.7 (build 3)  
Compared with v1.0.7 (build 2):
- Reverted backup/restore internals to the proven v1.0.6 build 1 architecture to improve relaunch and reinstall data persistence reliability.
- Kept automatic startup entitlement refresh so purchased license state is restored without manual actions.
- Removed user-facing restore-success interruption; purchase restoration now runs silently in background.
- Hardened release consistency for legal links and release-scoped metadata at build 3.

## ZH
发布版本：v1.0.7（build 3）  
相较于 v1.0.7（build 2）：
- 将备份/恢复核心链路回退到 v1.0.6 build 1 已验证稳定的实现，提升重装与重启后的数据保持可靠性。
- 保留启动时自动权益刷新，已购买 license 可在后台自动恢复。
- 去除恢复购买成功弹窗提示，恢复过程改为无感后台执行。
- 对 build 3 的法务链接与发布元数据做一致性收敛。
