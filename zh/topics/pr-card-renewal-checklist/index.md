<h2>从时间线开始，不要先急着填表</h2>
<p>续卡准备最耗时的部分，往往不是填写字段，而是发现旅行、地址、工作和护照历史长期分开保存，彼此已经对不上。先建立一条有证据支持的时间线，再把日期复制到申请中。</p>

<section class="story-panel">
  <p class="story-kicker">续卡前一周的陷阱</p>
  <h2>每份记录单独看都完整，放在一起却对不上。</h2>
  <p>日历说旅行星期一结束，航空账户显示星期二；地址历史又显示同一周搬家。冲突看起来不大，但只有把四类记录放在一起检查时才会出现。</p>
</section>

<h2>提前准备四类记录</h2>
<ol>
  <li><strong>旅行历史。</strong> 每一次有证据支持的离境与返回，包括短途和高频行程。</li>
  <li><strong>身份与护照历史。</strong> 新旧护照、身份信息和相关身份证明。</li>
  <li><strong>地址及工作或学习历史。</strong> 按申请要求的期间检查空白与矛盾。</li>
  <li><strong>支持性证据。</strong> 让用于解释或核实日期的资料随时可取得。</li>
</ol>

<h2>做一次跨记录一致性检查</h2>
<ul>
  <li>逐月比较旅行、地址和工作或学习记录。</li>
  <li>把不确定标记出来，不要填写一个方便的日期。</li>
  <li>确认每次离境都有合理返回，并且没有不可能的重叠。</li>
  <li>把枫叶卡到期提醒与居住义务计算分开。</li>
  <li>最终资料清单与资格核验以最新 IRCC 指南为准。</li>
</ul>

<h2>枫叶卡续卡旅行记录清单</h2>
<p>每段旅行至少保留离境日、返回日、目的地和日期来源，再与期间使用过的新旧护照、订票邮件、日历及可获得的边境记录逐项核对。没有证据支持的日期应继续标记为“不确定”，不要为了填满表格而猜一个方便的日期。</p>

<div class="callout"><strong>重要区别：</strong>枫叶卡过期不等于 PR 身份自动结束；卡片仍有效，也不等于自动证明符合居住义务。具体情况应以最新官方指引为准。</div>
