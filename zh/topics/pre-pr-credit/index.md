faq_items:
  - q: 成为永久居民前在加拿大的时间能计入入籍吗？
    a: 相关五年期间内，部分符合条件的临时居民或受保护人士时间可能按半天计算，最高折算 365 天。
  - q: 临时居留折算能用于 PR 居住义务吗？
    a: 不能。这项折算属于入籍 physical presence，不属于永久居民居住义务。
  - q: 最终应使用什么工具核验？
    a: 申请前应使用 IRCC 当前 physical presence 计算器和指引。
  - q: App 能决定某段临时身份是否符合折算资格吗？

<div class="direct-answer"><h2>成为 PR 前的加拿大居留时间能计入入籍吗？</h2><p>相关五年期间内，部分符合条件的临时居民或受保护人士时间可能按半天计算，最高折算 365 天。这项折算只用于入籍 physical presence，不用于 PR 居住义务。</p></div>

<section class="story-panel"><p class="story-kicker">窗口移动之后</p><h2>成为 PR 前的一年加拿大经历，不会永远留在计算窗口内。</h2><p>Leah 留学后成为永久居民。她每次改变计划入籍日期，五年窗口也随之移动。真正需要长期保存的不是某次显示的折算总数，而是每段可能符合条件的日期和当时身份。</p></section>

<h2>保留官方核验所需的输入</h2>
<ol><li>记录成为 PR 前每段在加拿大的期间和当时身份。</li><li>保留开始与结束日期的支持资料。</li><li>计划申请日期变化后重新计算。</li><li>最终申请结果使用 IRCC 官方计算器核验。</li></ol>
